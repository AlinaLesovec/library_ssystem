📚 Library System
Проект системы управления библиотекой, реализованный с использованием архитектуры MVC и базы данных SQLite.

⚙️ Функционал
Управление книгами (добавление, просмотр)
Управление читателями
Выдача и возврат книг
Работа с SQLite базой данных
Контроллеры для бизнес-логики

🏗 Архитектура
Проект построен по принципу MVC:
Models — работа с данными и бизнес-логика
Views — отображение (интерфейс)
Controllers — обработка действий пользователя
Database — работа с SQLite

🧪 Тестирование
В проекте реализованы автотесты с использованием pytest.
Запуск всех тестов:
py -m pytest -v
Проверка покрытия:
py -m pytest --cov=.

📦 Установка зависимостей
pip install -r requirements.txt
или через poetry:
poetry install --no-root

🚀 Запуск проекта
python main.py
или:
poetry run python main.py

📊 Требования проекта
MVC архитектура
Работа с SQLite
Обработка ошибок
Валидация данных
Автотесты (≥ 80% покрытия)
